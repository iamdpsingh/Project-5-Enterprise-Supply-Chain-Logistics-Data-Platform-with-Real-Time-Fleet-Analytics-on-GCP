# Enterprise Supply Chain & Logistics Data Platform with Real-Time Fleet Analytics

This repository contains the code and configuration for an end-to-end enterprise data platform built on Google Cloud Platform (GCP).

## Architecture

The platform processes structured, semi-structured, and unstructured data in batch and real-time. It features:
- Data Lake (Cloud Storage)
- Data Warehouse (BigQuery)
- Operational Database (Firestore)
- Batch Processing (PySpark)
- Stream Processing (Dataflow / Pub/Sub)
- Orchestration (Airflow)
- Transformation (dbt)
- Machine Learning (BigQuery ML)

For more details, see the `docs/` and `architecture/` directories.
